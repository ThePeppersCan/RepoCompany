Velmora V33.30 — Startup / Performance Hotfix

ROOT CAUSES REMOVED
- Travel map is no longer built on DOMContentLoaded or when Dragonbound merely opens.
- The large travel artwork is now loaded only after the player presses Travel.
- Travel artwork converted from ~3.84 MB PNG to ~0.62 MB WebP.
- Day-cycle polling reduced from 4 times per second to once per second.
- Removed repeated full Dragonbound button scans / getComputedStyle / getBoundingClientRect work from the timer.
- Day-cycle playable-state detection now uses the existing is-open / is-active classes directly.
- Username fallback no longer performs a DOM query every timer tick.

ALSO FIXED
- Travel-map Your Home now uses the existing Dragonbound home destination instead of opening My Bedroom.
- Overnight bedroom sleep now awaits the day-cycle morning result correctly.
- No sleep sprite position / angle / scale changes.
