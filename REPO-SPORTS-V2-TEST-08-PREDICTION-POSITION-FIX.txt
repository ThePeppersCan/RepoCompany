REPO SPORTS V2 TEST 08 — PREDICTION POSITION HARD FIX

ROOT CAUSE
The previous patches calculated a new prediction-box position in JavaScript,
but older accumulated CSS still contained top:...!important declarations.
Those stylesheet rules beat the normal inline top value, so visually the box
stayed in the same place.

FIX
- Removed legacy hard-coded prediction top positions.
- Runtime now measures the ACTIVE large central presentation card.
- Prediction box is placed exactly 10px below that card.
- Runtime sets top using inline !important so previous CSS cannot override it.
- Bottom/left/transform are also explicitly controlled.
- Position recalculates whenever the centre presentation changes.
