V29.2 — VELMORA ADVENTURES VIEWPORT / NAV / NPC HOTFIX

Apply over V29.1/current.

Fixes:
- Adventures dialog uses almost the full browser viewport.
- Bottom navigation is permanently visible instead of being pushed below the game panel.
- Navigation stays in one horizontal row and scrolls horizontally on narrow screens.
- Character creator option lists scroll inside the panel while BACK / CONTINUE remain visible.
- Removed the layout rule that made the creator content exceed its available grid row.
- Nearby NPC cards now receive direct click bindings in addition to the normal delegated Adventure handler.
- Dialogue auxiliary refresh failures can no longer prevent the NPC dialogue from opening.
- Adventure notifications are contained inside the Adventures dialog instead of relying on the site's global toast position.
- Reward/discovery banners are constrained to the visible dialog.
- Dialogue and processing overlays are bounded to the visible game viewport.

No SQL. No backend changes. No unrelated systems included.
