VELMORA: DRAGONBOUND
V33.81 — HOUSEHOLD BONDS & THE VELMORAN CALENDAR

WHAT THIS UPDATE DOES
V33.80 made each dragon an individual. V33.81 gives that individual a household, shared traditions and a calendar of recurring Velmoran days.

VELMORAN CALENDAR
- Added a deterministic 31-day fictional Velmoran Cycle.
- One Velmoran calendar day = one real-world Europe/London day.
- The accelerated Dragonbound house day/night clock remains completely separate.
- Fixed epoch prevents calendar drift and keeps the same calendar day shared across accounts.
- Epoch is 30 July 2026 = Day 1. On 23 August 2026 the calendar correctly resolves to Day 25 / Lantern Night.
- Added a small pinned parchment Day indicator on the Dragonbound home screen.
- Added a complete polished 31-cell calendar view with current-day stamping, event selection, event descriptions and upcoming events.
- Added Calendar as a full Keeper Journal tab.
- Normal days remain intentionally clean and are described as quiet Velmoran days rather than empty/missed content.

EVENT ATMOSPHERE
- Newleaf Morning: sparse drifting leaves.
- Mudhop Day: tiny muddy footprint motif.
- Moonwatch: restrained cool moonwash and stars.
- Heartbond Day: very sparse warm relationship glints.
- Greenwater Fair: small festival bunting.
- Lantern Night: warm edge light, tiny lanterns and golden motes.
- Frostwake: subtle frost edge and pale glints.
- Starhearth Eve: evergreen/gold star garland and warm motes.
- Starhearth: fuller evergreen/gold treatment, tiny lights/stars and warm hearth glow.
- Decorations are layered over the existing house; house artwork is not replaced.
- No festival music was added because none was supplied.

FESTIVAL BEHAVIOUR
- Event definitions are data-driven.
- Events apply small personality/furniture action biases only.
- Urgent Needs still outrank all festival flavour.
- Personality still matters: e.g. playful/muddy dragons enjoy Mudhop differently; Window Watchers favour Moonwatch; sleepy/cosy dragons react naturally to Starhearth/Lantern Night.
- No Keeper Marks, race rewards, economy or Dragon Racing XP changes.

HOUSEHOLD BONDS
- Added a persistent socialUniverse separate from personality and Bond.
- Keeper relationship now tracks familiarity/trust/affection/comfort as a social expression of the existing Bond rather than replacing Bond.
- Bedroom cats/dogs can become actual household companions for the dragon.
- Uses the currently selected/named VelmoraBedroom pet and preserves its real name and breed.
- Relationships grow only from actual interaction/proximity moments.
- Stages include Noticed, Curious, Familiar, Friendly, Playmate, Close Friend, Deeply Bonded and Favourite Companion.
- No harsh relationship decay.
- No fighting, injury or hostile pet behaviour.
- Jealousy/protectiveness remain harmless flavour dimensions only.

HOUSEHOLD PET VISITS
- The Bonds page can invite the currently selected bedroom cat/dog into the main Dragonbound house.
- Heartbond, Lantern Night, Starhearth Eve and Starhearth can also produce one automatic household-pet visit per session/day when a bedroom pet exists.
- Visitor uses the existing bedroom pet animation assets.
- Visitor pathing uses the existing Dragonbound navigation/collision helpers; it does not teleport through furniture.
- Actual close-proximity moments can produce gradual familiarity, play, quiet companionship, shared rest, window-watching or protective observations.
- The visitor RAF exists ONLY for the duration of a visible visit and is cancelled on house exit, Book/Travel/Calendar overlay, floor mismatch or visit timeout.
- Existing bedroom.js and pet movement/collision code are not modified.

MEMORIES / AUTHENTICITY
- Festival moments are not fabricated simply because the calendar says an event is active.
- A festival memory requires actual dragon/social activity during that event session.
- Minor event history is capped to 25 entries.
- Major event firsts are retained.
- First meaningful Starhearth records a permanent First Starhearth memory.
- Social moment history is capped to 30 entries.
- First relationship-stage milestones and first shared rests can feed the existing life scrapbook.

PERFORMANCE / SAFETY
- New module adds ZERO MutationObservers.
- New module adds ZERO setIntervals.
- Calendar is calculated on demand plus one scheduled UK day-boundary timeout.
- Relationship progression updates on real social events, not every frame.
- The only new requestAnimationFrame loop is the temporary visible household-pet visitor; it is explicitly cancelled when not needed.
- Festival particles/decorations are CSS-only and use a tiny number of elements.
- Festival CSS animations are paused while Book, Travel or full Calendar overlays cover the house and festival layers are removed on house close.
- No document.body subtree watchers.
- No permanent 100ms polling.
