V33.75 — Site Performance Guard

Goal
- Keep the website as smooth after opening/closing lots of features as it is after a fresh page load.
- Performance/lifecycle only: no intended gameplay, visual, reward, economy, audio-volume or balance changes.

Base
- Built directly on V33.74 Endless Combat Performance Recovery.
- V33.74 combat optimisations are preserved.
- Dragon Racing files are NOT modified by this patch.

Main changes
1. Removed the remaining permanent BODY-subtree MutationObservers from the current main script.
   - V33.74: 9 body-wide subtree observers.
   - V33.75: 0 body-wide subtree observers.
   - Binder preview, Hidden Cards, RCG desks and Foil & Fable now observe only their own UI roots or use direct-body discovery.

2. Quidditch TCG Binder lifecycle cleanup.
   - Legendary preview observer exists only during an active preview.
   - Binder reliability no longer watches every DOM insertion on the entire site.
   - Binder scroll-lock lifecycle is owned by its existing open/close wrappers.
   - Hidden Cards state observer is scoped to the binder dialog.

3. RCG lifecycle cleanup.
   - Exterior leaf spawning starts only while the exterior is actually open.
   - Submit / Inspection / Collection desk observers are scoped to the RCG dialog.
   - Slab Binder Library no longer polls every 900ms forever; it reacts to binder mutations instead.

4. Foil & Fable lifecycle cleanup.
   - Exterior leaf timer no longer exists while the shop is closed/interior is active.
   - UI audio observers watch only Fable overlays/toast nodes instead of every class mutation site-wide.
   - Voucher polish watches Fable roots rather than the full document subtree.

5. Background-tab reductions.
   - Daily/global XP leaderboard refreshes pause while the tab is hidden and refresh on return.
   - Homepage live-news rotation/network refresh pauses while hidden.
   - World Cup account/persistence refresh avoids hidden-tab work.

6. Repo Sports standings helper.
   - Points-column safety refresh keeps the same 1.2s visible cadence but does no row scanning while the relevant UI is absent/hidden.

7. Barry / Quidditch commentary tipping helper.
   - Its 1s / 5s / 30s safety work now runs only while Quidditch Mode is actually open and the tab is visible.
   - First-open sync is kept immediate via the existing open buttons.

8. Dragonbound background work.
   - Treat cooldown DOM updates only run while Dragonbound is open/visible.
   - Periodic skill-reward safety scan no longer performs background RPC work while Dragonbound is closed.
   - Event-driven skill rewards remain immediate.
   - Bedroom sleep code/positioning was not touched.

9. Admin-only diagnostics.
   - RepoPerformanceDebug.snapshot()
   - RepoPerformanceDebug.quickCheck()
   - No global requestAnimationFrame/setInterval/setTimeout monkey-patching.

Not changed
- Combat difficulty, enemies, weapons, waves, XP, GP or graphics.
- Dragon Racing gameplay, camera, rewards, Marks, audio, visuals, facing fixes or XP state.
- Dragonbound behaviour/sleep positioning.
- Canvas resolutions.
- Supabase schema/RPCs.
- Audio volumes.
- Existing animation timings.

Deployment
- Replace the current main site script with script.js from this patch.
- No index.html or asset changes are required.
