V33.75 — Site Performance Audit

Scope
- Main site script only.
- Based on V33.74.
- Goal: stop invisible/background/duplicate work without changing the experience.

MUTATION OBSERVERS
Before V33.75:
- 9 document.body subtree observers remained in the current script.
- Several watched all child additions and/or attributes across the entire site.

After V33.75:
- 0 document.body subtree observers remain.
- Remaining subtree observers are scoped to feature roots, including:
  * Quidditch TCG Binder dialog
  * RCG shop/binder dialog
  * Foil & Fable overlays
  * small specific text/status nodes
- Direct-body observers remain only where they are used as cheap discovery of a top-level dialog/node.

REQUESTANIMATIONFRAME AUDIT
Inspected core current loops and confirmed existing cleanup patterns are already present for:
- Gnome Ball: cancelAnimationFrame on stop.
- Standard/Endless Combat: stale RAF cancellation on start and cancellation on finish/exit retained from V33.74.
- Sailing: RAF cancelled on stop/finish.
- Quest game: previous RAF cancelled before start; cancelled on close.
- Level Hunter Canto: prior RAF cancelled on start and stop.
- Hunter Windmill: RAF cancelled on exit.
- Quidditch Mode: animation frame cancelled on close.
- Multiplayer Horde guest/host shutdown paths: combat frame cancellation retained.

No global RAF monkey-patch was added.
No game physics loop was paused in a way that could change elapsed-time/gameplay semantics.

SETINTERVAL / BACKGROUND WORK
Changed:
- Foil & Fable exterior leaf interval: now exists only while exterior is open.
- RCG exterior leaf interval: now exists only while exterior is open.
- RCG Slab Binder Library 900ms permanent safety poll: removed; replaced with scoped dialog observation.
- Barry Quidditch helper intervals: callbacks become no-ops while mode is closed/hidden.
- Dragonbound treat cooldown interval: no DOM work while Dragonbound is closed/hidden.
- Dragonbound skill reward safety interval: no RPC work while Dragonbound is closed/hidden.
- XP leaderboard periodic refresh: no hidden-tab network/DOM refresh.
- Homepage live-news ticker refresh/rotation: paused while hidden; refreshes on return.
- World Cup background refresh: hidden-tab guard added.

Intentionally retained:
- Timers that are authoritative gameplay/network heartbeats while their feature is active.
- Multiplayer/Quidditch background-watch mechanisms that intentionally preserve earned progress while tabbed out.
- Feature timers that are already properly cleared on close.

DOM HOT-PATH / HIDDEN WORK
- Repo Sports PTS helper no longer scans standings rows while the relevant UI is hidden/absent.
- Binder preview no longer reacts to unrelated page DOM mutations.
- Hidden Cards no longer reacts to Combat/Dragonbound/other feature class changes.
- RCG desk setup no longer reacts to unrelated site mutations.
- Fable SFX no longer watches every class mutation across the document.

CANVAS / COLLISION / OBJECT LIFETIME
- V33.74 already handled the identified Endless Horde hot-path work:
  * change-driven HUD writes
  * static backdrop cache
  * in-place effect cleanup
  * reduced temporary arrays
  * squared-distance checks where safe
  * cached enemy visual classification
  * stale RAF protection
- V33.75 deliberately does not reduce canvas resolution, enemy counts, particles or effect lifetimes.

NETWORK / SUPABASE
- No schema changes.
- No RPC signatures changed.
- Background refreshes are paused only where they are UI/state refreshes and safe to resume.
- Intentional multiplayer/gameplay heartbeat systems were not changed.

ADMIN DIAGNOSTICS
For the site-admin account:
  RepoPerformanceDebug.snapshot()
  RepoPerformanceDebug.quickCheck()

These report known managed state only. They do NOT monkey-patch browser timing APIs.

Remaining possible future hotspots (not changed because they are either intentional or need live profiling evidence)
- Long-running multiplayer networking sessions.
- Very dense Canvas scenes with legitimate entity counts.
- Old feature-specific safety intervals that are already cheap/no-op while closed.
- GPU-heavy effects that are intentionally part of the visual design.

Regression boundary
- This pass prioritised stopping invisible work over removing visible effects.
