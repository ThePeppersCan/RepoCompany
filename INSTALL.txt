REPO SPORTS WORLD CUP — LIMITED EVENT V1.7
Passport + corrected card reveal hotfix

CHANGES
- Card reveal now physically turns edge-on, swaps to the ACTUAL unlocked card image, then opens face-up.
  It no longer finishes on a mirrored World Cup card back.
- Supplied player-name reveal audio now plays at 100% volume.
- Adds the World Cup Passport beside the entire Limited Event menu.
- The eight supplied Round-of-16 ticket artworks fit into the eight Round-of-16 passport slots.
- Watching at least 10 minutes of an eligible live Round-of-16 fixture stamps that exact match ticket into the passport.
- Attendance is persisted server-side and short disconnects do not award offline time.
- Passport collection continues even after all match packs have already been earned.
- Retains the V1.6 pack-opening SQL ambiguity fix and transparent Hat Trick artwork.

INSTALL
1. Run world-cup-limited-event-v1.7-passport.sql once in Supabase SQL Editor.
2. Replace the website script.js with this package's script.js.
3. Merge the assets folder into the site root (preserve folders).
4. Ctrl + Shift + R.

NO RESET
The SQL does not reset existing World Cup packs, cards, opened packs, match-pack progress or prior fixture rewards.
