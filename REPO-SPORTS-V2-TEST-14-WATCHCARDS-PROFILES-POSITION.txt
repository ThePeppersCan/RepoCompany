HOVER PROFILE
- V2 Watchcards are now interactive/focusable.
- Hovering a Watchcard sends the viewer name + pointer position to the parent.
- The parent calls the ORIGINAL qmRenderWatcherProfile().
- The original full profile popup is therefore reused:
  total skill level, highest skill, highest-scoring pet, favourite TCG card,
  Watchcard background, avatar and existing original presentation.
- Hover also forces qmRefreshWatcherProfiles([viewer], true), so the profile is
  refreshed rather than relying on stale V2 data.
- Pointer movement reuses qmPositionWatcherProfileCard().
- Leaving/blur reuses qmHideWatcherProfile().
- The original popup is forced above the V2 full-screen overlay.
