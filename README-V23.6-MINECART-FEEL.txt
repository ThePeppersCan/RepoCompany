REPARTY V23.6 — MINECART MAYHEM PART 3
=======================================

PURPOSE
-------
Pure gameplay feel / clarity / fun pass for Minecart Mayhem only.
Built directly on V23.5.

MAIN CHANGES
------------
- Reworked Minecart into a clearer authored-pattern racer instead of random hazard soup.
- First section teaches the game with clean pickup lines and single hazards.
- Two deliberate track splits only: SAFE / BALANCED / RICH.
- Clear action language: JUMP, DUCK, SWITCH, SLALOM, PICK YOUR LINE.
- Hazard patterns always preserve a readable reaction or escape route.
- Snappier lane switching, more forgiving jump/duck windows and shorter hit slowdown.
- Hits hurt Flow/Boost but do not kill the run or leave long dead periods.
- Flow now matters: clean actions build Flow and charge Boost.
- Boost is more useful: speed surge, pickup magnet and smash-through for rocks/carts.
- Pickups are smaller/cleaner; obstacles now have distinct readable silhouettes.
- Rivals are visually quieter and no longer overpower the playfield.
- Race position is based much more on actual progress; pickups no longer make the player instantly jump to 1st.
- Final Descent becomes a faster prism-heavy closing sprint.
- Final 1.8 seconds now get a proper FINISH LINE push instead of just timing out.
- HUD simplified to Position, Score, Route, Flow, Boost and round progress.
- Minecart instructions shortened and clarified.

ISOLATION
---------
Only Minecart Mayhem and its Reparty metadata/cache-buster changed.
Goblin Bomb Party and the other 10 Reparty game functions are unchanged from V23.5.
No Repo Sports, World Cup, TCG, Binder, RCG, Passport, Supabase, or economy files are included.

INSTALL
-------
Apply over V23.5/current Reparty build.
No SQL migration required.
