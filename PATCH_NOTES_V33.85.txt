Velmora Dragonbound V33.85 — Commands & Tricks Open Training Board

This is a direct rebuild of the actual dragonbound-commands.css, not another wrapper around the menu.

Changes
- Removed the visible outer command panel box.
- Removed brown banner styling from the Commands & Tricks header.
- Removed brown card backgrounds from every command button with direct high-specificity overrides.
- Rebuilt the 12 commands as a clean 4-column training matrix separated by fine hairlines rather than chunky cards.
- Converted the Current Dragon section into a slim interface line instead of another boxed panel.
- Locked commands recede cleanly instead of becoming muddy disabled tiles.
- Close button, progress lines, status tags and footer redesigned to match the Dragonbound teal / sage / restrained-gold visual language.
- Preserved command behaviour, proficiency, cooldowns, requirements, success calculations, furniture actions and listening HUD.

- This patch intentionally contains dragonbound-commands.css itself. V33.84 targeted the wrong layer and could only decorate the outside of the menu.
