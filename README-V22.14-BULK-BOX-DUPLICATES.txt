REPO SPORTS — V22.14 BULK BOX / DUPLICATES

Normal TCG Binder
- Existing Hidden Cards drawer is now CARD STORAGE.
- Two tabs: HIDDEN CARDS and BULK BOX.
- BULK BOX automatically groups duplicate raw card IDs from the player collection.
- Shows spare quantity, total physical copies, rarity and card art.
- Duplicate raw cards remain available for RCG grading; they are not inserted as duplicate visual slots in the normal binder.
- Counts update immediately after pack pulls / collection refreshes.

RCG Slab Binder
- Existing Hidden Slabs drawer now has HIDDEN SLABS and DUPLICATES tabs.
- DUPLICATES groups slabs by card ID when the player owns 2+ graded copies.
- Shows each individual slab grade and whether it is ON DISPLAY or STORED.
- Stored duplicate slabs can be restored straight from the duplicate group.
- Search and rarity filters work in both views.

No Supabase migration is required. This uses the duplicate card copies and individual slab records already stored by the live database.
