V32.52 — Dragonbound Furniture Shop + Build Inventory

LIVE DATABASE
- Added a dedicated Dragonbound soft-currency wallet: Keeper Marks.
- New accounts/build users start at 0 Keeper Marks. Earning Keeper Marks is intentionally not implemented yet; future Dragonbound activities can credit this wallet through trusted server-side logic.
- Added 64 furniture catalogue entries from the supplied Dragonbound Build Inventory handoff.
- Added persistent per-account furniture inventory quantities.
- Added persistent per-house furniture placements (house, floor/room, item, position, rotation and direction).
- Added server-side/RPC purchase, place, move/rotate and put-away operations.
- Purchases are server-authoritative and atomic. The browser cannot choose the price, balance, owner or item count.
- Direct authenticated writes to wallet/inventory/placements are denied; authenticated clients use the validated RPCs.
- All four new tables have RLS enabled.

FREE TEST FURNITURE
The shop contains three one-time free claims so the complete loop can be tested before currency earning exists:
- Emerald Canopy Bed (bed-0) — FREE
- Meadow Washstand (bath-0) — FREE
- Rope Tug Post (toy-1) — FREE
A free item can only be claimed once per account through the purchase RPC.

BUILD BUTTON / INVENTORY
- The existing top-left Build artwork now has a working transparent hotspot.
- No generic/brown hover button has been introduced.
- Build opens the new Dragonbound Build Inventory UI.
- Owned Furniture shows only items the player actually owns.
- Quantities distinguish total owned from currently available (not placed) copies.
- Search, category, rarity and sorting controls are included.
- The supplied 64 transparent furniture sprites are used directly.

FURNITURE SHOP
- Build Inventory includes a dedicated Furniture Shop tab.
- Bonnie Bramble's existing Shop button now opens the furniture shop instead of the old "coming soon" message.
- Paid furniture shows its Keeper Mark price.
- With 0 Keeper Marks, paid purchases correctly remain unavailable.
- The free bed, bath and toy can be claimed immediately for testing.
- Buying/claiming adds the furniture to the persistent Build Inventory.

HOUSE PLACEMENT
- Selecting an available owned furnishing enters placement mode in the current house.
- Furniture follows the cursor and can only be confirmed on a recognised upstairs/downstairs floor navigation zone.
- Existing furniture is checked to prevent obvious overlaps.
- Placing an item reduces its available inventory count while preserving total ownership.
- Placement records persist to Supabase and reload with the house.
- Furniture is drawn beneath the baby-dragon layer so the dragon can move naturally in front of it.
- Furniture collision polygons are exposed to the existing baby-dragon navigation system; a furniture change event is fired after placement/editing.

EDIT BUILD MODE
- Edit Room allows placed furniture to be selected in the house.
- Existing furniture can be moved.
- Existing furniture can be rotated 180 degrees.
- Put Away removes the placement and restores that copy to the available Build Inventory count.
- B opens/toggles Build Inventory at home; Escape exits the current build mode.

PERSONALITY / FUTURE INTERACTIONS
- Catalogue items expose interaction tags such as sleepable, comfortable, playable, inspectable, food, warm, hideable, washable and climbable.
- A global furniture interaction provider exposes placed items + tags to the V32.51 personality system for future bed/bath/toy interaction behaviours.
- This version does not yet add bespoke furniture-use animations; it establishes the persistent placement/interaction architecture first.
