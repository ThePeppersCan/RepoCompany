REPO COMPANY V18.1 — HIDDEN CARDS + BINDER STYLE SIDE CONTROL V13
=================================================================

This pass does four things:
- stabilises the Hidden Cards holder so it stops jumping during page turns
- moves the holder closer to the binder and lowers it for cleaner alignment
- places the Binder Style button directly underneath the Hidden Cards holder using the supplied icon art
- removes Binder Style from the bottom plaque so only the collection page text remains there in a cleaner themed box

Install:
- replace script.js
- add/overwrite assets/quidditch-tcg-binder/binder-style-icon.png

Other bundled binder assets are included for convenience.
