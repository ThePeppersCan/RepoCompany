FINAL-WHISTLE ROOT CAUSE
The completion function RETURNS a field named `match_serial`.

Using:
  ON CONFLICT(match_serial)

inside that same PL/pgSQL function can collide with the output variable.

Recovery V2 uses:
  ON CONFLICT ON CONSTRAINT repo_sports_recorded_matches_pkey

so PostgreSQL has no ambiguous identifier.

LEADERBOARD RECOVERY
If the official historical snapshot table already contains rows, it is left
untouched.

If it is empty, the SQL attempts to capture the existing historical Repo Sports
career RPC again. It combines:
  historical frozen snapshot
  +
  official new live Repo Sports player deltas

Legacy Quidditch is still excluded from official records after the snapshot is
captured.
