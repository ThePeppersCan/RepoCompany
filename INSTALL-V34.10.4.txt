DRAGONBOUND V34.10.4 — TEAM CHANGING ROOMS

Install this over V34.10.3.

1. Extract the ZIP into the root of your existing website.
2. Keep the dragonbound-career-mode/team-rooms folder exactly as supplied.
3. Allow the existing launcher and Career Mode files to be overwritten.
4. Upload/publish the files, then hard-refresh with Ctrl+F5.

What this adds
- The Career hub's middle display now shows the changing room belonging to
  the team saved in the active career.
- Sunscale, Valecroft, Ember & Oak, Quickquill, Wyrmwell and Fizzy Drake each
  have their correct changing-room image.
- Existing saves are supported because the display uses their stored team ID.
- Images fill the display without stretching, with a controlled crop that
  keeps each team's emblem visible.

Changed site files
- dragonbound-career-launcher.js
- dragonbound-career-mode/index.html
- dragonbound-career-mode/career.js
- dragonbound-career-mode/career.css
- six PNG files inside dragonbound-career-mode/team-rooms/
