REPO SPORTS V2 TEST 37 — GLOBAL CLOCK FIX

Fixes the Test 36 prematch getting stuck around -30.

Cause:
Every live-state poll reset the interpolation anchor to performance.now().
Repeated early/stale server samples therefore kept restarting the local clock.

Fix:
- same-match elapsed time is monotonic and cannot rewind
- stale/out-of-order parent RPC responses are rejected using server_now_ms
- parent same-match elapsed is also monotonic
- an immediate smooth-state fetch follows each host heartbeat
- new match serial still resets cleanly to 0

Zero-viewer behaviour remains:
- any open RepoCompany browser can advance the global broadcast
- zero open website browsers = no heartbeat = no game progression
- returning later resumes the frozen match
