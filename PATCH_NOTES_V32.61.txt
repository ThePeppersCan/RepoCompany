V32.61 — Dragonbound Furniture Controls + Shop/Inventory UI Overhaul

Placement controls
- R now turns/flips the furniture currently being held.
- Mouse wheel now resizes held furniture in 5% increments (wheel up = larger, wheel down = smaller).
- Existing Q/E and +/- shortcuts remain available.
- Placement HUD and footer show the new shortcuts.

Shop / Build Inventory UX
- Rebuilt the furniture browser into a clean cool-green/obsidian Dragonbound interface; removed the brown-heavy presentation.

- Added paginated browsing (15/12/8 items per page depending on screen width) so the 160-item catalogue is manageable.
- Category controls are now a compact horizontal grid rather than a tall left rail.
- Added robust wheel routing and explicit overflow/overscroll handling for the furniture gallery and item inspector.
