Velmora patch V33.45 — Dragon Racing Track Selection Menu

- Added all 9 supplied track previews to the existing Track Select screen.
- Velmora City Circuit is the default first selection and is presented as the Level 1 starter course.
- All tracks are currently selectable; no level locks are enforced yet.
- Track rows are fitted cleanly into the left panel with thumbnail, name and compact region/difficulty text.
- The selected map preview is placed directly inside the existing Track Preview box.
- Added concise Track Details: difficulty, setting, course profile and future access status.
- Added Race Style text to the existing top-right Race Style panel.
- Added selection via the left rows, keyboard, and the existing bottom previous/next arrow art.
- Text is clipped/ellipsized or line-clamped to prevent any spill outside the menu panels.
- Existing shine/mouse-light/glint effects remain intact.
- No race launching or level locking has been implemented yet; this patch is selection/presentation only.
