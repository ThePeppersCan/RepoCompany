DRAGONBOUND CAREER MODE — V34.11.2 STORY JOURNEY

This is a changed-files-only upgrade for V34.11.1.

INSTALL
1. Copy everything in this ZIP into the same web2 folder where V34.11.1 is installed.
2. Allow Windows to merge the dragonbound-career-mode and story folders.
3. Choose Replace when asked about existing files.
4. Upload/deploy the updated web2 folder as usual.
5. Hard-refresh the website so the V34.11.2 cache version loads.
