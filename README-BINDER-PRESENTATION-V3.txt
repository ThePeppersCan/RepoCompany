REPO COMPANY V18.1 — BINDER PRESENTATION V3
===========================================

Built on top of the previous Binder Presentation Fix V2.

CHANGES
- Removed the rectangular gold/modal border around the cover view.
- Removed the rectangular border around the open binder view.
- Previous / Next buttons are hidden while the binder is open.
- Click the physical LEFT edge of the binder to turn backward.
- Click the physical RIGHT edge of the binder to turn forward.
- Page edges get only a subtle hover chevron / light cue, rather than looking like buttons.
- Existing drag-between-spread helpers still appear when actually dragging a card.
- Binder colour themes now tint / illuminate the supplied BIND artwork instead of replacing it.
- All standard background effects have been rebuilt to run inside the physical open binder.
- Existing legendary/full-spread effects remain supported and are clipped to the binder.
- Pocket finishes now style the real transparent plastic pocket overlay:
  Classic Gold / Crystal Edge / Shadow Matte / Platinum / Enchanted.
- Cards are fractionally fuller in the pockets without stretching.
- Binder Style control and Hidden Cards remain intact.

INSTALL
1. Replace script.js.
2. Merge the included assets/quidditch-tcg-binder/ folder as before.

No SQL/database changes are required.
