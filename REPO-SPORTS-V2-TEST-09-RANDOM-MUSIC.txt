REPO SPORTS V2 TEST 09 — TRUE RANDOM MUSIC SHUFFLE

AFFECTS
- Repo Sports Quidditch V2
- Repo Sports World Cup

BEFORE
- Opening song was random.
- After that, songs always advanced in fixed numerical order.
- This made the playlist feel like the same loop.

NOW
- All available Quidditch background tracks are placed into a shuffled bag.
- The order is randomly shuffled.
- Each track plays once before that bag is refilled.
- When the bag refills, it reshuffles again.
- The first track in the new bag cannot equal the track that just finished.
- No immediate back-to-back repeat.
- The last played track is remembered in sessionStorage.
- A new V2 match / World Cup match avoids starting with that same track again.
- Same existing match-music volume and fades.
- Music 3 remains included as one of the four available tracks.

NO GAMEPLAY CHANGES.
NO CSS CHANGES.
NO SQL UPDATE REQUIRED.
