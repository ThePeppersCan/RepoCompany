REPO SPORTS LIVE — FAIL-SAFE ROTATION

LATEST SYMPTOM
The client reaches a stable completed match and stays on:
  FINALISING LIVE RESULT / SYNCING NEXT LIVE MATCH

ROOT ISSUE
The browser could still be blocked by another tab/browser owning the short
global host lease.

This is especially possible when an older site tab remains open and continues
heartbeating using an older Repo Sports build.

FIX
- completion RPC is now attempted even when this browser is not current host
- server normally accepts the active host
- once authoritative active_elapsed_ms >= 300,000 ms, ANY viewer may complete
  the CURRENT serial
- current match_serial still must match
- recorded match PK still prevents duplicate stat counting
- stat persistence is wrapped in a protected subtransaction
- if an optional leaderboard/stat write ever fails, LIVE SERIAL STILL ADVANCES

Result:
A database/stat problem or stale host can no longer freeze the broadcast.

FULL-TIME UI
- NEXT LIVE MATCH button removed completely
- no manual next-match action
- transition remains fully automatic
- waiting copy now says FINALISING LIVE RESULT…
