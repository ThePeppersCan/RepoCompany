LEVEL HUNTER: VELMORA ANIMAL CENTRE — CANTO PREMIUM V4
THE WINDMILL VISITOR

INSTALL
1. Replace your current site script.js with the script.js in this ZIP.
2. Merge the included assets/level-hunter folder into your site's existing assets/level-hunter folder.
   - assets/level-hunter/windmill-floor-1.png
   - assets/level-hunter/windmill-floor-2.png
3. Hard refresh the site: Ctrl + Shift + R.

IMPORTANT
- There is NO index.html replacement in this package.
- There is NO new SQL requirement if you already ran the existing Level Hunter wildlife-save SQL.
- This build is based on the current Canto Major Gameplay Redesign V3 and keeps the existing 19% in-world encounter-camera focus.
- Existing Level Hunter animal/food/forage/clue assets from your prior package must remain in place.

QUEST FLOW
Finish Darwin's first Canto fieldwork quest -> speak to Darwin about Canto fieldwork -> meet/enter the Windmill.
You can also enter after the first quest is complete; Darwin will begin the Windmill assignment inside if it has not been started yet.

CONTROLS INSIDE WINDMILL
WASD / arrows  Move
Shift          Careful movement
E              Context interaction / advance dialogue
I              Field Satchel
J              Wildlife Journal
Esc            Close picker/panel or exit when standing at the lower-floor door

No separate encounter screen is used. The player remains in the explorable interior throughout the wildlife encounter.
