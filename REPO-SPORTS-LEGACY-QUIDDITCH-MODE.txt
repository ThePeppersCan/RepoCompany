REPO SPORTS — LEGACY QUIDDITCH MODE

ADDED
- New Legacy Quidditch Mode image button.
- Placed immediately to the RIGHT of the Repo Sports World Cup header button.
- Uses the supplied Legacy Mode artwork with the checkerboard background removed.

LEGACY BEHAVIOUR
- Opens the original fullscreen Quidditch Mode.
- Restores its original server-backed global/background live clock.
- Two people opening Legacy are watching the same old fixture, clock and score.
- Legacy keeps the original arenas, pets, commentary and flavour presentation.

RECORDS
Legacy does NOT affect the official Repo Sports competition.

The patch adds a one-time historical snapshot:
  historical Repo Sports career snapshot
  +
  new Repo Sports Live league deltas

The official left career board and right 18-team standings read ONLY that system.
Future Legacy matches are ignored by official:
- player goals
- player matches
- wins/losses
- win rates
- club standings

The old Legacy career panel itself now displays:
  LEGACY MODE · NOT RECORDED

Any old prediction payout coming from the Legacy server is also ignored by the
browser and is not credited into the displayed account balance.

   RUN-ONCE-LEGACY-QUIDDITCH-ISOLATION.sql

2. Copy:
   index.html
   script.js

   into C:\Users\Isaac\Desktop\web2\

The historical snapshot locks on its FIRST successful run. Re-running the SQL
later will NOT recapture stats that the Legacy mode may have changed.
