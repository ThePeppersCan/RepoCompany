V37:
- Central presentation-only personality system.
- Stable profiles for all 48 World Cup players.
- Archetype, celebration style, reaction style, idle style, teammate style,
  confidence style and cosmetic movement flavour.
- Rare signature celebrations (~28% where configured).
- Per-player recent reaction/celebration memory.
- Personality-weighted miss/save/interception/conceding/foul reactions.

- PERSONALITY_DEBUG available and disabled by default.
- Referee remains outside the player personality system.

MECHANICS REGRESSION SAFETY:
- Physical interception/tackle contest retained.
- Interceptor still has to physically close the ball/lane before a challenge.
- Failed interception recovery retained.
- Shot blocking/save reach gate retained.
- Selected save is not granted if defender/keeper is too far from target.
- Clean save / parry / block logic retained.
- Contact/foul proximity requirement retained.
- No personality profile is consulted by tackle, interception, shot, save,
  possession, scoring or winner RNG.
- V36.1 30-second prematch anthem/kickoff timing retained.
- Existing V35 flow, reactions, celebrations, replay stings and broadcast package retained.
