Velmora Dragon Racing — Patch V33.60
===================================

Patch-only update.

Changes
-------
- Removed the blimp / hot-air-balloon / flying decorative sprites completely.
- Removed the old cloud image sprites too.
- Clouds are now generated entirely with CSS gradients and soft shading.
- Reduced the live cloud count to four.
- Each cloud gets randomized scale, height, opacity, speed, drift and gentle vertical movement.
- Clouds move cleanly left-to-right and re-randomize after leaving the screen.
- No external sky image assets are required by this patch.
