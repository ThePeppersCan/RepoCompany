V32.58 — Hestholm furniture pointer + floor hotfix

This replaces the problematic placement-input path rather than nudging the same zones again.

- Build input catcher now sits in screen space over the whole house, outside the animated/scaled house world.

- Hestholm placement edge checks now use exactly the same margins as projection.
- Existing placements, inventory, ownership and Supabase data are unchanged.
