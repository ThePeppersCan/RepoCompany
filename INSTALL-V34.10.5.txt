DRAGONBOUND V34.10.5 — HOVER + DISPLAY POLISH / ONE SAVE

Install this over V34.10.4.

1. Extract the ZIP into the root of your existing website.
2. Allow the four existing files to be overwritten.
3. Upload/publish them, then hard-refresh with Ctrl+F5.

What this changes
- Removes the hard rectangular hover outlines from sponsor cards and Career hub
  hotspots, replacing them with softer movement, light and glow.
- Adds a slow cinematic drift, ambient pulse and occasional screen-light sweep
  to the active team's changing room in the middle display.
- Allows one Career save per website account.
- Accounts with a save can no longer start another Career; they are directed to
  Select a Dragon and their existing save instead.
- The database also enforces the one-save rule, including across devices or
  simultaneous browser sessions.

Changed site files
- dragonbound-career-launcher.js
- dragonbound-career-mode/index.html
- dragonbound-career-mode/career.js
- dragonbound-career-mode/career.css

The six team-room images from V34.10.4 are unchanged and are not duplicated in
this smaller patch.
