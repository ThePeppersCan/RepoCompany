REPO COMPANY — V38.15 TCG BINDER RUNTIME FIX

MODIFIED FILES ONLY
- index.html
- script.js

ROOT CAUSE
The main script contained two binder installers.

The old installer:
- front cover
- ONE two-page spread
- back cover

The newer full binder installer appeared later, but it immediately crashed on:
CARD_CATALOG.length

CARD_CATALOG is private to the Quidditch TCG pack-system closure, so it is not
visible to the later binder installer. That ReferenceError stopped script.js at
that exact point. This explains all four symptoms together:
- only one two-page spread remained
- card drag/drop from the new binder never installed
- hidden-card drawer never installed
- binder customisation code later in the file never executed

- Current local binder catalog: approximately 131 card definitions.

  repo_tcg_binder_54_layout_<username>
