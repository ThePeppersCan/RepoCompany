DRAGONBOUND V34.10.6 — ACCOUNT DRAGONS IN TEAM ROOMS

Install this over V34.10.5.

1. Extract the ZIP into the root of your existing website.
2. Keep the dragonbound-career-mode/team-avatars folder exactly as supplied.
3. Allow the existing launcher and Career Mode files to be overwritten.
4. Upload/publish the files, then hard-refresh with Ctrl+F5.

What this adds
- The Career hub's middle display now combines the active team's changing room
  with the signed-in player's own baby dragon in that team's uniform.
- The image is selected from both the saved team ID and the Career save owner.
- Supported account/dragon pairs:
  CovidPanda / NighLight
  CatAsthma / September
  Kat / Opal
  Emlux / Turi
  Proco / Wally
  Smokedrope1028 / Pipsqueak JR
- The correct pairing returns automatically whenever the account loads its
  existing Career save.
- Avatars use a soft floor shadow, entrance animation and restrained idle motion.
- Only the active account/team image is loaded by the browser.

Changed site files
- dragonbound-career-launcher.js
- dragonbound-career-mode/index.html
- dragonbound-career-mode/career.js
- dragonbound-career-mode/career.css
- 36 optimised WebP images inside dragonbound-career-mode/team-avatars/

The team changing-room backgrounds from V34.10.4 remain unchanged and are not
duplicated in this patch.
