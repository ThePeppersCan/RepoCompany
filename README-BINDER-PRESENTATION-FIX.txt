REPO COMPANY V18.1 — BINDER PRESENTATION FIX
============================================

Fixes the binder presentation shown in the supplied screenshots.

CHANGED
- Binder launch view is now ONLY the large binder cover, centered on the screen.
- Removed the surrounding modal/frame/footer/Hidden Cards controls from the cover view.
- Added a restrained idle float + hover lift/glow to the cover.
- Clicking the cover opens the collection as normal.
- Open pages now use the supplied BIND.png artwork as the actual binder background.
- Existing transparent pocket/plastic overlay is retained above the cards.
- Cards are enlarged slightly inside each pocket without clipping or stretching them.
- Existing saved binder arrangements, page count, drag/drop, Hidden Cards and Binder Style systems are preserved.

INSTALL
1. Replace script.js with the included script.js.
2. Merge the included assets/quidditch-tcg-binder/ folder into the same site path.
   - repo-binder-open-spread.png is the supplied BIND.png artwork.
   - repo-binder-pocket-overlay.png is the transparent sleeve overlay.
