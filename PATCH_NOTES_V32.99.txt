VELMORA: DRAGONBOUND — V32.99
Commands, Tricks & Training Relationship
22 August 2026

NEW — KEEPER COMMANDS
• Added a dedicated Commands control to the owned Dragonbound home.
• Added 12 starter commands: Come Here, Sit, Stay, Go to Bed, Eat, Bath Time, Fetch, Drop It, Go to Furniture, Roar, Tiny Flame and Fly to Perch.
• Commands are unavailable while visiting another Keeper or while Build Mode is active.
• Only one command can be active and one can be waiting; click-spam cannot build a huge queue.

LEARNING, NOT A ROBOT
• Every command has persistent proficiency: Unknown → Learning → Familiar → Reliable → Mastered.
• Command response chance uses proficiency, Bond, relevant dragon skills, mood, needs and personality.
• New commands have a visible reaction delay. Familiar/Reliable/Mastered commands become progressively quicker to recognise.
• Failed commands use harmless learning reactions instead of appearing broken: halfway recall, lying down instead of sitting, getting distracted by a fetch toy, tiny squeak, smoke instead of a controlled flame, etc.
• Personality differences are included for Velcro Baby, Independent Spirit, Patient/Impatient, Toy Obsessed, Hoarder, Tiny Menace, Professional Napper, Splash Addict, Little Pilot, Fearless and Coward-style behaviour.

ANTI-SPAM TRAINING BALANCE
• Command execution remains available during learning recovery, but meaningful command XP has its own per-command recovery timer.
• Recovery grows with proficiency (roughly 8–30 minutes).
• Added a soft real-hour training-fatigue window: several different meaningful attempts are fine, but mass-spamming commands sharply reduces and eventually pauses learning XP until recovery.
• No Keeper Marks/currency are awarded from command practice.
• Existing skill XP cooldowns remain separate and untouched.

PHYSICAL COMMANDS
• Go to Bed / Eat / Bath Time / Go to Furniture reuse the real existing furniture interaction pipeline, including gradual care, skill cooldowns and physical mounting.
• Fetch searches for a genuine carryable toy, uses the physical carry system, and can travel one-way toward the Keeper-side safe target for the command rather than using a fake text-only fetch.
• Drop It can interrupt an active carry cleanly.
• Fly to Perch attempts a real safe indoor flight first, then lands/settles at a suitable perch; if a flight zone cannot start, it falls back to the safe furniture route.
• Tiny Flame and Roar use small baby-safe visual reactions only; no destructive combat behaviour was added.
• Come Here uses the current house navigation map and safe walkable nodes. No teleporting.

WELFARE / AUTONOMY
• Optional Daily Life events stand aside when a Keeper command starts.
• Stair climbing, flight landing and active care/furniture interactions are treated as busy; commands wait for a safe moment rather than breaking them.
• Very low Energy/Hunger can make demanding training wait/refuse.
• Stay is temporary and can end early if a genuinely urgent need appears.
• Existing autonomous needs, personality, Daily Life, 3x V32.98 need decay and baby-growth lock remain intact.

JOURNAL
• Added a Training & Commands section to the Dragonbound Keeper Journal.
• Shows known/learning count, mastered count, attempts, per-command proficiency, observed response rate and learning recovery.
• Clicking a command card opens Command Details with what the command does, which skills matter, current response estimate, practice readiness and any unlock requirement.
• Meaningful firsts/stages can become Little Memories, including First Command Understood, First Fetch, First Tiny Flame and command-stage/mastery memories.

PERSISTENCE
• Command proficiency, attempts, successes, per-command recovery, recent attempts, training-fatigue timestamps and milestone state save inside the existing dragon memory snapshot.
• No parallel save system was added.
• Existing dragons receive a very conservative bootstrap from real prior history only (for example bed usage, object carrying or fire practice); no existing dragon is granted mastery.

BACKEND
• No Supabase schema change is required. Commands live in the existing dragon_memory JSON persistence path.
